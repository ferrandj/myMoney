Application sur le téléphone

Sur Android, ouvre cette page dans Chrome en HTTPS : le bouton ci-dessous (ou « Installer l'application » dans le menu ⋮) ajoute myMoney à l'écran d'accueil, comme une application.

Sécurité

  • Base de données chiffrée par SQLCipher (AES-256) : comptes, titulaires, adresses, RIB, opérations et contacts. Documents originaux chiffrés un par un (AES-256-GCM), illisibles sur le disque et téléchargeables ici.
  • Clé dérivée du mot de passe par Argon2id ({{ (settings.argon2_memory_kib / 1024)|int }} Mio, {{ settings.argon2_time_cost }} passes), jamais écrite sur le disque.
  • Verrouillage automatique après {{ settings.auto_lock_minutes }} min d'inactivité{% if settings.unlock_password_file %} : désactivé, car le déverrouillage automatique est configuré{% endif %}.
  • Cookie de session {{ 'sécurisé (HTTPS)' if settings.cookie_secure else 'non sécurisé : active HTTPS puis MYMONEY_COOKIE_SECURE=true'|safe }}.
  • Aucune connexion à une banque : l'application ne reçoit que les documents que tu lui donnes. Seules sortent du NAS les cotations (CoinGecko, Yahoo Finance, BCE, pour les positions saisies à la main) et la lecture des pages publiques de service-public.gouv.fr et impots.gouv.fr pour les taux : aucune donnée personnelle n'est envoyée.
