Mode d'emploi

{% if cls.type == 'enablebanking' %}
  1. Crée un compte gratuit sur enablebanking.com, puis une application en environnement Production.
  2. Dans « Redirect URLs », ajoute {{ request.base_url }}connections/callback (ou l'URL publique de ton NAS). Si ton NAS n'est pas en HTTPS, mets n'importe quelle URL https : tu colleras l'adresse de retour à la main.
  3. Télécharge la clé privée (.pem) générée, copie son contenu ici avec l'Application ID.
  4. Clique sur « Activate by linking accounts » dans le panneau Enable Banking (mode restreint gratuit, tes comptes uniquement).
  5. Une connexion par banque : Fortuneo, BforBank, Hello bank!, Boursorama, Revolut, Trade Republic…

Le consentement bancaire (DSP2) dure 180 jours : l'app te demandera de te reconnecter ensuite.

{% elif cls.type == 'gocardless' %}

Clés dans le portail GoCardless Bank Account Data → User secrets. Limite : 4 synchros par jour et par compte.

{% elif cls.type == 'exchange' %}
  • Binance : Gestion API → créer une clé, cocher uniquement « Enable Reading ». Restreins à l'IP de ta box.
  • Kraken : Settings → API → permissions « Query Funds » et « Query Ledger Entries » uniquement.
  • Ne coche jamais trading ou retrait.
{% elif cls.type == 'woob' %}

Woob se connecte au site de ta banque avec tes identifiants web, comme le faisaient les agrégateurs avant la DSP2. Utile pour l'assurance-vie, le PEA, le PER… Si ta banque demande une validation (SMS, appli), l'app te la demandera.

Modules : fortuneo, bforbank, hellobank, boursorama, bnporc, cragr, creditmutuel, caissedepargne, lcl, ing, spirica, linebourse, amundi… Liste complète : woob.tech.

{% elif cls.type == 'traderepublic' %}

Après l'enregistrement, Trade Republic envoie une demande de connexion dans l'application mobile : valide-la puis reviens cliquer sur Continuer. La session est conservée chiffrée.

{% elif cls.type in ['evm', 'bitcoin', 'solana'] %}

Seules les adresses publiques sont nécessaires. Ne saisis jamais ta seed phrase ni une clé privée : aucune app légitime n'en a besoin pour lire un solde.

Confidentialité : les API publiques voient les adresses consultées. Si tu as un nœud ou un mempool sur ton NAS, indique son URL.

{% endif %}
